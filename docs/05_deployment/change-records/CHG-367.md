# CHG-367 — C3 (1/2): Fluss probe baked into the ingestion image, run via compose exec

- **Status:** complete for the probe boundary — the daily Fluss lag probe no longer needs a host
  JDK on any host. The class ships in the ingestion image and `day_run` execs it inside the running
  container; the host `javac` + `target/cp.txt` route is deleted. The EOD/scheduler/golden-recipe
  half is CHG-368.
- **Filed:** 2026-09-28
- **Source:** C3 from `logs/full-project-audit-20260928/REPORT.md` (a recipe-built fresh VM has no
  `javac`, no `target/cp.txt`, and the runner's `localhost:9123` probe would fail there).

  compiles the new Dockerfile lines; the static tests keep the wiring from drifting in between.

  parameter and its `logs/day/collect` mkdir are gone (one test call updated).
