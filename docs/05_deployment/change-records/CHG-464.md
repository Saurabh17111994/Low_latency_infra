## What changed

`r2_archive_selection.py` -- the DEC-060 rule as pure functions:

- `parse_selection(csv)` -- trims, drops empties, dedupes, and **refuses an
  empty result** (a config error must not mass-disable);
- `plan(live, selected)` -> `SelectionPlan(enable, disable, ok, missing)` --
  exactly the listed tables enabled, every live-enabled table outside the list
  disabled ("not any other"), a listed table missing from the catalog reported
  (never skipped), an empty live flag map treated as "nothing enabled".

`plan()` is the single rule source: the sync tool (S2) and the gate preflight
guard (S3) both consume it, so live-check and apply can never disagree.
