## What changed

### XC-3 — `cluster_check.py`: a surface that could not be read is a FAIL

`collect()` ignored the return code of `node inspect` / `service inspect` and
defaulted a failed or unparseable result to `{}`. Downstream, an empty spec
means "no constraints, no ports": a real replica shortfall was reclassified as
topology-limited (WARN instead of FAIL), and `placement-spread`,
`global-coverage`, `published-ports` skipped the service and reported OK.
Both probes now record every failure in `data["probe_errors"]` (with the
daemon error text) and `check_probes_readable` fails the run — the same
fail-closed rule the harness fingerprint gate already applies (P6-411:
evidence we never read is not a pass). The evidence JSON carries the errors.

### XC-4 — `CandleVerify.java`: TRADE-branch brace + symmetric diagnostics

The second `}` on the `if (px > 0) { … } }` line closed the
`if ("TRADE".equals(type))` block, so `a.sumDeltaTrade += delta;` and
`a.tradeRows++;` executed for every row: the parity sum included QUOTE deltas
(when a quote carries one), and `tradeRows` was never 0, killing the
"absent window had no trades" diagnostic. The brace now closes only the
inner `if`. The three OHLC diagnostics (`high_short_of_raw`, `low_above_raw`,
`range_wider_than_raw`) are tallied for every judged window instead of being
split across the match/mismatch branches (diagnostics only — they never
decided pass/fail).

### XC-5 / AS-037 — `holistic-analyze.py`: an unsampled counter is not a clean zero

A missing/empty `tm-prom-dedup-late.tsv` left `last_sample_ms=0`, so
`dup_in_window`/`late_in_window` were 0 and G7a/G7b passed vacuously while the
run still printed "G7: data-quality guards passed (dedup exact, late-drop
covered…)". A missing `tm-prom-invalid.tsv` printed a measured-looking
"total=0" for F6. Both legs now use `tsv_sample_count` /
`counter_leg_note`: when events were expected and the file was never sampled,
the leg is appended to the `unavailable` list (visible hole, not a failure),
G7 prints "counter-exactness NOT MEASURED", and F6 prints "NOT SAMPLED". The
outer handler binds the `OSError` instead of `pass` (clears the aislop
finding; the inner per-line `except ValueError: pass` is the accepted
AS-036 site and is untouched).
