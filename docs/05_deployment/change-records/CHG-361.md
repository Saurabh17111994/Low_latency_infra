# CHG-361 — ephemeral-VM daily mode: profile, stop gate and the 15:45 EOD record

- **Status:** complete — the daily VM runs with no morning flags (`.env.vm`),
  `stop` refuses to strand the day before the EOD archive is confirmed, and the
  EOD scheduler records its last clean run for that gate. Plan decision D3
  amended (no 24×7 posture).
- **Filed:** 2026-09-28
- **Source:** operator decisions 2026-09-28: the production VM is a **fresh
  disk every morning** (the PC runs the stack only while powered on), and
  **EOD → R2 starts after the Indian market close**, 15:45 IST.
