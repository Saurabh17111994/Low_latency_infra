# CHG-202 — signal-chain E2E harness: fail fast, export fully, exit honestly (W37 slice 1)

- **Status:** recorded — fixed and guarded (2026-09-17)
- **Filed:** 2026-09-17
- **Source:** Wave 37 audit (`p6-ops-scripts-tests-chaos-audit.md` §10):
  P6-017 (CRITICAL), P6-191, P6-192 (HIGH), P6-533–P6-537 (MED),
  P6-777 (LOW) on `code/01_platform/04_scripts/run-signal-chain-e2e.sh`.

## What happened

The E2E wrapper burned long runs before failing and could false-pass:

- Default `E2E_BROKER=faketool` build could never succeed: `go build -o
  faketool ./faketool` targets a path where the `faketool/` source directory
  lives (`open faketool: is a directory`); the binary path `FAKETOOL_BIN`
  already pointed at `faketool/faketool`.
- Missing out-of-repo manifest hard-exited both broker modes instead of
  falling back; only 2 of 5 Arrow vars were exported although go-bridge
  reads all five (arrow-mode TOTP login failed downstream).
- Fixed `/tmp` checkpoint dir collided across concurrent runs and reused
  stale RocksDB state; no input validation, no toolchain/backend preflight,
  no classpath-file hygiene — a dead backend wasted the 30-minute test.
- Finale had no `failIfNoSpecifiedTests`: with `SignalChainLiveE2ETest`
  retired (0f3e5952) the script always "No tests to run" → exit 0,
  a live silent false-pass. `INGESTION_JAR_DIR` was dead config.

## What changed

- `code/01_platform/04_scripts/run-signal-chain-e2e.sh` — faketool
  `-o faketool/faketool`; manifest warn-and-unset (+ guarded export for
  `set -u`); all-five Arrow export via `if`; PID/timestamp checkpoint dir
  with trap on the default only; validation block (positive-int minutes /
  parallelism, `rocksdb|hashmap` enum anchored on `SignalJobConfig`,
  `HOST:PORT` OTEL check); preflight (`command -v go/mvn`, 5 s `/dev/tcp`
  probes for Fluss + OTEL); cp-file pre-`rm` + `-s` gate (no EXIT trap —
  it would clobber the checkpoint trap); explicit `cd` +
  `-DfailIfNoTests=true -Dsurefire.failIfNoSpecifiedTests=true`
  (now fails LOUD — the honest state while the test is retired);
  `INGESTION_JAR_DIR` deleted.
