# CHG-359 — F8: KV snapshots for the dev stack (mount + 1-minute interval)

- **Status:** complete — the tablet and coordinator mount the persistent
  `fluss-remote-data` store, the dev env template sets
  `FLUSS_KV_SNAPSHOT_INTERVAL=1m`, and a guard test pins mount + knob together.
  A restart now loads the latest snapshot and replays at most the tail since
  it; the fresh-start rehearsal measured stop 51 s / start 87 s on a wiped host.
- **Filed:** 2026-09-28
- **Source:** F8 root cause from the 2026-09-28 cold-start drills: every start
  logged `No snapshot found` per KV bucket and rebuilt from log offset 0
  (`candle_live` ~90 s x 16 buckets, 22 min 56 s total).

```text
change_record_id: CHG-359
scope: enable periodic KV snapshots for the dev stack so a restart recovers from the latest snapshot instead of replaying the whole retained changelog. The knob already existed (`kv.snapshot.interval: ${FLUSS_KV_SNAPSHOT_INTERVAL:-0s}` in the tablet's FLUSS_PROPERTIES) but the snapshot store, `/tmp/fluss-remote-data`, had no persistent mount: the tablet and the coordinator (which serves the lake-snapshot RPC from the same directory) lost every snapshot at container recreation — and at the default 0s none was ever taken. This change (1) mounts the `fluss-remote-data` volume on the tablet AND the coordinator, (2) sets `FLUSS_KV_SNAPSHOT_INTERVAL=1m` in the dev env template (the compose default stays `0s`, so a production deck switches deliberately), and (3) adds an offline guard test that pins the mounts and the knob. Root cause measured 2026-09-28: every cold start logged "No snapshot found" per bucket and rebuilt its RocksDB KV from log offset 0, dominated by candle_live/candle_closed (~90 s x 16 buckets). No DDL, connector, sink, strategy or Flink-state change.
owner: platform
date: 2026-09-28
affected_artifacts: code/01_platform/01_docker/docker-compose.yml, code/01_platform/01_docker/.env.example, code/01_platform/04_scripts/tests/test_08_local_compose_f8_snapshots.py, docs/06_operations/01-runbooks.md
compatibility_class: COMPATIBLE
savepoint_impact: none (Fluss-server-side snapshots; no Flink state, checkpoint or savepoint interaction)
test_updates: +1 file tests/test_08_local_compose_f8_snapshots.py (4 offline tests): tablet mount, coordinator mount, prod-safe `:-0s` compose default, dev env template `1m`. Failing-first: the env-template test failed before the line was added (`FLUSS_KV_SNAPSHOT_INTERVAL=1m` not found); a mutation that removed the coordinator's mount line failed test_coordinator_mounts_the_snapshot_store.
rollback_behavior: revert -> the mounts and the env line disappear; snapshots stop being persisted (or are written to the container layer and vanish on recreate) and cold starts replay the whole changelog again (measured 22m56s at 58.6M raw records); no state to migrate
plan_tasks: docs/plans/2026-09-22-fluss-1.0-native-adoption.md (A5)
```
