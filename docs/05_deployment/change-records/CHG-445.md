## What changed

1. **`ContextProvider`** — the fetch machinery inside the strategy host. Byte-budgeted
   LRU cache (default 8 MB/subtask, ~192 B/entry estimate), 32 in-flight fetches,
   100 ms fetch timeout, 250 ms retry cooldown, single flight per key, bounded cooldown
   map. Heap-only: nothing in Flink state. Mailbox discipline: Fluss client threads
   touch exactly one structure (the concurrent arrivals map with a fetch sequence);
   `drainArrivals()` promotes completions on the operator thread and drops arrivals
   whose sequence was superseded (timeout/retry). Counters/gauges registered as
   `compute.context.*` (15 series).
2. **`FlussCandleFetcher`** — native Fluss lookup against `candle_closed` (DDL 33),
   decoded to `ContextCandle` (paise/millis units); fail-closed at open; owns and closes
   its connection. **Measured fix:** the first smoke caught Fluss rejecting a
   `lookupBy` list that equals the full primary key
   (`IllegalArgumentException: Can not perform prefix lookup ... Please use primary key
   lookup (Lookuper without lookupBy) instead`, job exception saved at
   `logs/context-c1-smoke-20260930-084753/smoke/job-exception.json`); the lookuper is
   now built as `newLookup().createLookuper()` — the exact-PK form.
3. **`ContextView`** — the strategy-facing read-only view (mailbox-thread only). Not
   handed to strategies in this change; the contract (`onContextReady`, last-live
   snapshot, timer wake-up) and the first consumer are C2/C3, separately gated.
4. **`SignalJobConfig`** — `STRATEGY_CONTEXT_ENABLED` (default false; `true` without
   `STRATEGY_HOST_ENABLED=true` is a config error) plus the operator-approved knobs:
   `STRATEGY_CONTEXT_CACHE_BYTES=8388608`, `STRATEGY_CONTEXT_MAX_INFLIGHT=32` (sanity cap
   4096), `STRATEGY_CONTEXT_FETCH_TIMEOUT_MS=100`, `STRATEGY_CONTEXT_RETRY_COOLDOWN_MS=250`.
5. **`StrategyHostFunction`** — creates the provider in `open()` when the flag is on
   (first `close()` override closes it); no fan-out/dispatch change. Package-private
   factory seam so the open/close lifecycle is provable without a cluster.
6. **`pipeline-lib.sh`** — submit pass-through for the five keys: a flag set in the host
   shell now reaches `SignalJobConfig.fromEnv()`. Static-pinned by the new platform test
   (the same gap class as W1's `FLUSS_SCANNER_FETCH_WAIT_MAX_TIME_MS`).
