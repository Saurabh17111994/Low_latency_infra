## What changed

- `SignalJobConfig`: new component `legacyCandleSinksEnabled`
  (`LEGACY_CANDLE_SINKS_ENABLED`, default `true`). Cross-check: `false` while
  `MERGED_CANDLE_FEATURES_ENABLED=false` throws, naming both flags — a silenced
  legacy path without the merged writer would persist no candles at all.
- `SignalJob`: `legacySinkBranch(stream, enabled, uid)` — enabled returns the
  stream untouched; disabled returns `stream.filter(row -> false)` named and
  UID'd per branch (`candle-live-legacy-guard` / `candle-closed-legacy-guard`).
  The guard sits **before** `MultiTimeframeSinks.sinkLive/sinkClosed`, so the
  sink operators and the keyed first-write-wins state remain deployed (restore
  anchors) and simply receive nothing.
