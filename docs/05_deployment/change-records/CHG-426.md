## Notes

- **Why the old test existed and was wrong:** `conflictAndStaleRequireHalt` asserted STALE → halt with the
  rationale "older version rejected — must not overwrite newer state". Rejection and halting are two
  different decisions: the reject is real (the store never regresses), but a re-delivered old event is
  a replay, not a divergence — production treats it as a soft reject and keeps serving the key.
- **No production caller:** the helper is only used by tests today; production switches on `Outcome`
  directly. The fix is therefore vocabulary alignment (the plan's "one semantic vocabulary holds"
  after M1-6), and the truth table now pins it for future callers.
- **The helper's contract is now exhaustively asserted:** all six outcomes appear in one test, so a
  future enum member forces a decision here rather than silently inheriting a default.
