## Notes

- **Why the failure reached the full gate:** the smoke's unit fixture pinned the scalar types (STRING/BIGINT/INT/DOUBLE/BOOLEAN/BYTES). `feature_values` landed 2026-09-27, and the last *full* gate before 2026-09-29 predates it — the recent soak runs were scoped (`--steps 1-3`) and never touch the live drill.
- **Fixture-signature semantics:** the default map is one entry keyed off the declared key/value types (`MAP<INT, DOUBLE>` → `{index+1: 1.0+index}`), so `isSmokeFixtureRow` still recognises only our own placeholder rows — a different map is rejected.
- **`copyFieldValue` deliberately unchanged:** it only copies primary-key fields, and no DDL declares a MAP inside a primary key; the new guard would fail first if one ever did (it walks every column of every DDL).
- **The DDL corpus is the input:** the guard reads the committed `*.sql` files directly (not the manifest), so a DDL added without a manifest regeneration is still covered.
