## What changed

- **`SignalAuditJson` (new)** — one shared, deterministic v2 document for
  `score_inputs`: `strategy` (id/tf/side/window/levels/range/triggerPrice),
  `fire` (`path` `live|arm`, detection/evaluation timestamps), `candle` (the
  triggering forming row on the live path, the arming closed candle on the arm
  path) and `market` (the full 42 latest-known values + both change clocks +
  their ages, read from `MarketView`). Null conventions are explicit: the
  market model's `0 = not provided` renders `null`, a never-seen clock renders
  `null` while age `0` stays a real number, and non-finite derived values
  render `null` so the document is always valid JSON. Built only at fire time —
  the hot path pays nothing.
- **`N7RangeBreakoutStrategy`** — overrides the view-aware
  `onLiveTick(RowData, StrategyView, Collector)` and
  `onClosedCandle(RowData, StrategyView, Collector)` defaults to capture the
  shared market view, then runs the same evaluation as the legacy forms (which
  stay the implementation, so direct callers and tests are unchanged). Both
  fire paths (`evaluate` live, `onClosedCandle` arm-time) now pass the fire
  path and the candle in context into `buildRow`, which stamps the v2 document.
  `formation_snapshot_ref` and the 22-column row contract are untouched.
