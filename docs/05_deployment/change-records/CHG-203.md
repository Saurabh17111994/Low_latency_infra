# CHG-203 — CEP guards: wider net, honest exits, no vacuous passes (W37 slice 2)

- **Status:** recorded — fixed and guarded (2026-09-17)
- **Filed:** 2026-09-17
- **Source:** Wave 37 audit (`p6-ops-scripts-tests-chaos-audit.md` §10):
  P6-036, P6-037, P6-038 (HIGH), P6-322 (MED) on `cep_guard.sh`;
  P6-039, P6-040 (HIGH), P6-323, P6-324 (MED) on `cep_module_check.sh`.

## What happened

- The guard scanned only `pom.xml` + `*.java`/`*.scala`: a CEP coordinate
  via Gradle/sbt/TOML or a Kotlin import bypassed it while it printed OK.
- grep stderr was swallowed (`2>/dev/null || true`): infra failures scanned
  as clean. Missing roots exited 1, indistinguishable from CEP hits, and the
  wrapper mislabeled every non-zero guard exit as "found CEP references".
- A scan root starting with `-` was parsed as grep options (no `--`).
- The wrapper's JUnit leg had no `failIfNoTests` (vacuous pass if the test
  vanished) and unquoted `${MVN_FLAGS:-}` allowed glob expansion.
- Standalone `-f $POM` looked wrong but is the only possible shape: R-272
  keeps compute out of the root reactor, so `-pl :compute` cannot resolve.

## What changed

- `code/01_platform/04_scripts/cep_guard.sh` — includes add `*.kt`,
  `*.kts`, `build.gradle`, `build.gradle.kts`, `settings.gradle`,
  `settings.gradle.kts`, `build.sbt`, `libs.versions.toml`,
  `extensions.xml`; `--` before `"$ROOT"`; grep stderr captured to mktemp
  (non-empty = infra → exit 2, output surfaced); R-091 missing-root → exit
  2; exit 0 + `OK:` line preserved.
- `code/01_platform/04_scripts/cep_module_check.sh` — [1/2] captures guard
  output, branches exit 2 (INFRA message) vs exit 1 (CEP-hit message);
  [2/2] gains `-DfailIfNoTests=true
  -Dsurefire.failIfNoSpecifiedTests=true`, `set -f`/`set +f` around the
  unquoted flags var, and a P6-324 comment (standalone is deliberate;
  `com.trading:common` resolves from `~/.m2` — refresh via
  `mvn -f code/pom.xml -pl common install` after touching common).
- `.../02_compute/.../CepDependencyGuardTest.java` — lockstep parity-leg
  update (suffixes, filenames, grep includes, javadoc); forbidden literals
  still assembled from parts.
- `code/01_platform/04_scripts/tests/test_cep_guards.sh` — new: 10 pins on
  the exit contract (clean/kt-hit/gradle-hit/dash-root/missing-root/
  unreadable-tree), hermetic tmp fixtures.
