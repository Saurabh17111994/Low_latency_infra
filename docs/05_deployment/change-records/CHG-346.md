## Decision summary

| Candidate | Bytes/row (64 features) | Decode p50 | Why not chosen |
|---|---|---|---|
| **MAP<INT,DOUBLE> (chosen)** | 358 | 35 µs | — |
| ARRAY<DOUBLE> + version | 348 | 24 µs | 2.9% byte edge costs a versioned-position contract on every reader; per-TF sparse features need per-TF layouts |
| JSON string | 366 | 330 µs | parser per read, serializer on the write path, text edge cases |
| MAP<STRING,DOUBLE> | 513 | 80 µs | +43% bytes for repeated key names |

Stored rows/s is window-driven (~308/s across 6 timeframes) and does not change with the
DataStream → HFT tick rate; the encoding optimizes feature churn, not tick rate. Evidence:
`logs/feature-spike-20260927/REPORT.md` (raw run `run.log`).
