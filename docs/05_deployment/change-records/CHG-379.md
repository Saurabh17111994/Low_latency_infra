## Notes

- **Mutation 2 is recorded as not caught.** The inline-stop mutation passed the service-level test
  because that service never started its writer workers, so its `shutdown()` returns without the
  drain that would block an inline stop. The daemon dispatch is therefore a structural guard
  (verified by inspection against `shutdown()`'s worker join), not a test-verified one; the elapsed
  assertion (`onWriterDrop` < 1 s) stays as a guard for future shutdown paths that do block.
- **One episode, not one record per dropped tick:** a halted tracker rejects every tick, so the
  journal write and the stop request sit behind one CAS. Per-tick work is a counter bump and a log
  line only.
- **SERVER_REJECTED stays non-fatal:** that is a data condition (the row's day is outside the
  table's retention) handled by the writer's outcome listener and already accounted; only the
  admission-time drops route through `onWriterDrop`.
