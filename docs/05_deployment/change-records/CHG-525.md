## What changed

Four commands, one per stage of the chain, all printing tables:

| Command | View | Mechanism |
|---|---|---|
| `make watch-raw ARGS=20` | newest `raw_table_1` ticks (live follow) | existing `show-ticks.sh` / `TickTableViewer` |
| `make watch-live` | strategy-host live-path flow: operator in/out per second, busy/backpressure, live-path counters, `tick_to_strategy` / `ingest_to_strategy` p50/p95/p99 (worst subtask) | new `strategy_live_board.py` (Flink REST, read-only) |
| `make watch-candles ARGS=20` | newest `candle_features` rows: token, tf, window, close, sealed, features map, per-tf counts | existing `candle-features-table.sh --mode tail` |
| `make watch-signals ARGS=20` | newest `Signal_Candidates` rows: time, symbol, token, rule, side, action, qty, tf/trigger/range parsed from the audit; `ARGS="--full"` prints the complete v2 audit; `--rule R` filters | new `SignalCandidatesViewer` + `signal-candidates-table.sh` |

- `SignalCandidatesViewer` resolves every field index from the live schema by name
  (a reordered table fails loudly), reads the LOG via the offset-paged `LogScanner`
  (KV snapshot fallback), and retains only the newest N in a min-heap.
- `strategy_live_board.py` picks the RUNNING `signal-job-compute` job, matches the
  `multi-tf-aggregator` / `strategy-host` vertices case-insensitively, and prints
  the last job states + start hint when no job is RUNNING (exit 0, not an error).
- `docs/commands/COMMANDS.md` gains section D2 with the four commands and the
  honest limit on #2: operator state is heap-only (DEC-059 closed-only storage),
  so the live board proves flow/latency, while row content is verified from
  `watch-raw` (source), `watch-candles` (sealed output) and `watch-signals`
  (`--full` audit = the market snapshot the host read at fire time).

## Why

- Before this, the only operator views were the raw viewer, the candle scratch
  probe and census tools (rule census, latency census); signals had no row view
  at all, and the live path had no view at all.
- The design reuses the established probe pattern (compile on host, run inside
  `01_docker_trading-net`, JRE-only image) and adds no production path.
