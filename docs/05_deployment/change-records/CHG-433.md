## Notes

- **The compose deck was the spec:** it learned the data+datalog pair from the 2026-09-05 catalog loss;
  the production deck never got the second half. Mirroring compose is exactly the H3-2 pattern (dev
  works / prod fails), and the test reads compose as the reference rather than hard-coding the shape.
- **A shared volume is its own failure:** the first mutation run (datalog mount removed) was red, but the
  second (two members sharing `zk-datalog-1`) initially passed — the test only compared data vs datalog
  *within* a member. The assertion now tracks every mounted source across members and fails on a repeat;
  the re-captured mutation is red. This is the P5-001 tablet-split lesson applied to ZK.
- **Why not `docker stack config` as evidence:** the render needs every `:?`-guarded image env, and the
  four locally built images are retired as pins (no digest exists to supply — FACT-009). The stack suite
  parses the real file with the same YAML loader and checks Swarm legality; a render would add nothing
  the suite does not already assert, and inventing digests is forbidden.
