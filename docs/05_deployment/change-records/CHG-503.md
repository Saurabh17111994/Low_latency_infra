## What changed

- **`r2-delete-prefix.sh` (new)** — the first sanctioned delete path in the
  repo. Dry-run by default (lists every key + size, sends no mutating
  request); `--apply` deletes, then re-lists every prefix and exits 1 if any
  object survived. Refuses empty, duplicate and overlapping prefixes before
  any request; refuses a prefix that is or covers the live Iceberg metadata
  `lake/default/raw_table_1/metadata/` unless `--allow-live` is passed.
  Credentials travel through the environment (P6-158); prefixes are normalized
  to a trailing slash so `table` cannot also match `table_backup/`.
- **`07-lake-archive-ops.md`** — new "Deleting objects (operator cleanup)"
  section with the tool's usage, guards and the 2026-10-01 cleanup record; the
  DEC-060 bullet's "never delete" is amended to point at the guarded tool.
