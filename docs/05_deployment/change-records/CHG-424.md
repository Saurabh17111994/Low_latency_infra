## Notes

- **Why not extend docs-audit C16:** C16 checks that a documented key is *mentioned* by ingestion
  code — a value can drift silently under it (exactly what happened). The registry adds the
  statement of record (the call text with default/range) and the row's required substrings.
- **The registry is fail-closed on new keys:** a future config key documented in the dossier without
  a registry entry fails the suite with the exact fix (add the mapping). That is the same shape as
  the feature-registry pin: the registry is the single place a new key must be registered.
- **Presence pins for secrets/paths:** keys whose rows state no value (credentials, paths) keep the
  quoted-key presence pin — the registry is complete, but only value-bearing rows carry value pins.
- **`INGESTION_ZERO_ACK_TIMEOUT_MS` stays undocumented by design:** it is an internal watchdog knob;
  the registry only covers documented keys, so it is not listed.
