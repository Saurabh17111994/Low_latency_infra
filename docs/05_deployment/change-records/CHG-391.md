## Notes

- **What counts as a window:** `ws_stream_once` returns `Ok` only for a stream that was live and
  ended (close, timeout, corrupt frame); a failed connect is `Err` and is not counted, and a
  shutdown close is excluded by the `tx.is_closed()` guard.
- **Reconcile scope:** one query per registered node ref + the mass command. Querying a node ref
  that already has a venue order id would be harmless, but the registry carries no per-order
  mutable state; the list is the registry's node refs, bounded by the process's order count.
- **Registry growth:** entries live for the process lifetime (a daily restart clears them); a
  route context is ~450 B boxed, node entries are a string + tag.
