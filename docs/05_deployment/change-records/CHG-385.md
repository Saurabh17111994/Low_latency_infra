## Notes

- **One constant:** `CONTROL_CONTRACT_VERSION = BridgeEvent.CONTRACT_VERSION` keeps a single accepted
  version; the BridgeEvent compact constructor still validates (defense in depth), but a
  wrong-version record never gets that far.
- **Nothing downstream sees it:** the return precedes `record_type` routing, so slot health, metrics
  gauges and the bridge-event path are untouched — readiness cannot pass on a foreign-version record.
- **Contract corrected:** the NDJSON-era text said an unknown version is "thrown"; the live behavior
  (and the proto comment) is quarantine + return.
