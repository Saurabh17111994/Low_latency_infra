## Notes

- **Why always-on:** the audit found the switch parsed and exported but never read on the proto
  path, and the only validator overload took Base64/hex strings — so no live tick ever had its
  bytes verified. Integrity is not a mode to remember: the switch and its test class are gone,
  and the no-off-switch test fails if any key, constant, field or diagnostic reopens it.
- **Wire truth:** the Go bridge writes the raw 32-byte digest (`go-bridge/batch.go`: `h[:]` of
  `sha256.Sum256(raw)`; `transport_test.go` asserts len 32). The old Java fixtures carried a
  64-char hex ASCII string — wrong shape, and the reason the byte[] path had to exist.
- **Bounded:** the 540 B packet cap (largest broker frame) runs before hashing, so an oversized
  payload is rejected without a digest pass (P1-076).
- **Ordering:** the gate sits before freshness/instrument/validity, so every downstream reason
  now presumes verified bytes — `IngestionServiceTest.blankPayloadHashQuarantined` (P1-249) was
  updated from `INVALID_VALUES` to `MISSING_PAYLOAD_HASH` accordingly, and the reason vocabulary
  test grew to 10.
