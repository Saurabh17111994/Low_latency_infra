## Why

The value-equality scan on 2026-09-21 found the live Arrow password and TOTP key in 15 git-ignored
`logs/soak/monday-gates-*/compose-config.log` files. The mechanism is one line of the gate: `docker
compose config` interpolates, so logging its output writes every resolved value to disk. It would have
produced a sixteenth log on the next run.

The obvious one-word fix, `--no-interpolate`, was rejected: it removes the leak but also removes the
step's ability to catch a missing required variable, which is most of why the step exists. Removing a
check to fix a leak trades one defect for another, silently.

So the render still runs and its status still decides the step, and a filter sits between the render and
the log. Identification is by exact value rather than by name pattern, because a pattern guesses and a
value does not: the candidates are the values in the process environment and in each `--env-file`, minus
the standard shell variables and minus values too short or too plainly non-secret to be credentials.
Over-redaction is the safe direction, so the longest candidate is replaced first and no fragment of a
real value can survive.

Both statuses are captured because a pipeline's status is the last command's. Under `set -u` a second
assignment resets `PIPESTATUS` and the second slot disappears, so the array is captured once; the wiring
test pins that. A redactor failure fails closed: an unfiltered log is not evidence that the config
renders.

The record line in `docs/08_implementation/05-execution-core.md` is the second half. It named the live
broker app id, and the repository is public, so the id is published. The id is replaced with the
placeholder style that file already uses, and the note records why. Removing it cannot unpublish it —
that is what the rotation is for — but the next commit will not carry it again.
