## Findings recorded (not fixed here)

- The DDL remains a proposal: production apply stays blocked (DDL hazard); the dev smoke in S3b
  needs an operator-approved way to create the table (recorded there).
- Retention/lake are conservative defaults (7d log TTL, lake off) — an open operator item once
  consumers state their retention requirement.
- The manifest generator records `bucket_key: null` for this entry even though the DDL declares
  `bucket.key = instrument_token` — the same as the candle tables; left consistent with them.
- Re-emitted windows after a restore upsert the same PK with deterministic values (convergent);
  unlike candles there is no first-write-wins filter, so a registry change legitimately rewrites
  a recomputed window.
