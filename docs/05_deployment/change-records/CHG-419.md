## Notes

- **The blind spot was real, not theoretical:** 86 tracked `*.sh` vs 83 under `code/`; the three
  root scripts were never in either lint run. Mutation 2 is the proof the fix binds: a syntax error
  in `show-ticks.sh` now fails `make static-check`, and would have passed before.
- **Why a shared script and not two matching one-liners:** the plan's words are "one lint
  enumeration". The scope test pins the shared script's output to `git ls-files` minus exclusions,
  so the two sites cannot drift even if one of them is later edited.
- **Fail-closed twice:** the enumeration itself exits 3 on an empty list, and gate step 1 keeps its
  "no shell scripts found to check" FAIL — an empty list can never certify as "0 failures".
- **Exclusions kept for untracked trees:** `target`/`third_party` currently match no tracked
  `*.sh`, but the rule stays so a vendored or generated tree can never be linted (or silently
  trusted) by accident.
