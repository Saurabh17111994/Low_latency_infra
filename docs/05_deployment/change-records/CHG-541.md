## What changed

1. `docker-compose.yml` job-env anchor (shared by jobmanager / taskmanager / compute launcher):
   `CHANGELOG_STATE_BACKEND: ${CHANGELOG_STATE_BACKEND:-false}` — the REST-submitted SignalJob
   `main()` runs in the JobManager JVM, so the flag must live in the job process environment,
   not on the launcher's command line.
2. `.env.vm.example` (tracked production VM template): `CHANGELOG_STATE_BACKEND=true` — the daily
   VM needs no morning flag (`day_run.py load_vm_env` loads `.env.vm` into the environment).
3. `.env` (local, gitignored): `CHANGELOG_STATE_BACKEND=true`; `.env.vm` (local, gitignored, new):
   the same, so local `make day` covers both submit paths (compute launcher REST and
   `rollout-savepoint` `flink run`).
