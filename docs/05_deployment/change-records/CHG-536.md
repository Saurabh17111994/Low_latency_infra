## What changed

### XC-24 — `TokenCountReconcile.java`: the quarantine census can actually run

The probe read `ingestion_quarantine` (a LOG table, `table.log.ttl=2d`, no
primary key) with `table.newScan().createBatchScanner(tb)` and no limit. The
pinned fluss-client 1.0.0 rejects that: the `TableScan` class carries the
literal message **"BatchScanner over a Log Table requires limit to be set"**
(verified in the jar, 2026-10-03), and a *limited* batch scan returns only the
first stored SEGMENT of a bucket — never a census. So the quarantine count
threw on every run (or, before P6-118, silently under-counted); the raw table
was already read correctly with the offset-paged `LogScanner`. The probe now
reads both tables through `scanLog` (parameterised with a `RAW`/`QUAR` output
label), `scanBatch` is deleted, and the class doc records why. The gate's
shell test gains three source guards, red before the fix.

### XC-25 — `IngestionConfig.java`: the Standard feed is selectable again

The Arrow-feed section header said "HFT only — the Standard feed was removed
2026-08-14". Since the 2026-09-24 channel switch the standard token stream is
live and selectable (`ARROW_FEED=token|hft`, DEC-039), so the header now says
so. The HFT-only env keys under it are unchanged.

### XC-26 — `SequenceGapMonitor.java`: proto only

The thread-safety note said "NDJSON + proto paths may alternate after a
restart". The NDJSON pipe transport was removed 2026-08-29 (proto-only
default); the note now reads "proto path only".

### XC-27 — `CandleAccumulator.java`: `lastIngestTs` is emitted

The JSDoc claimed the field is "NOT written to any output row, NOT part of any
table schema". Since the platform-speed KPI probe (CHG-491) it is written to
the forming/live row as `CandleLiveColumns.INGEST_TS`; the doc now says that,
keeps "never used by candle math", and records the pre-CHG-491 wording.

### XC-28 — `EncryptedExportEodOffloadExecutor.java`: not wired yet

The JSDoc said the class "replaces" the fail-closed executors "when a master
key is configured". `EodControllerTool`'s `--offload` list is
`none|mock|lake` — there is no encrypted branch, so the class is test-only
wiring today. The doc now says "intended to replace … once a master key is
wired" with a dated wiring note.

### XC-29 — `VersionGate.java`: no CI caller

`requireAllPinned` was documented as "used by CI before building images"; the
only caller is `VersionGateTest`. The Javadoc now states that (tests cover it;
no CI caller wires it as of 2026-10-03).

### XC-30 — `SyntheticWorkload.java`: benchmark claim

The class doc said "used by benchmarks"; `bench-throughput.sh` uses `faketool`
and the unit suite has no perf test. The doc now says "used by the mock arrow
server" (its actual caller).
