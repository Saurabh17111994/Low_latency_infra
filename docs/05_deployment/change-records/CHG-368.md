## Notes

- **Unset stays unset:** the compose pass-through uses list form so the controller's
  `System.getenv().getOrDefault("EOD_TABLES", null)` still sees null when the operator set nothing,
  and its fail-closed refusal is unchanged.
- **Canonical compose form:** the literals are separate list elements (the same shape the daily
  runner uses), and `DAY_COMPOSE` — the Makefile's registered form — wins whenever `make day`
  exported it; the compose-form contract test stays green with no registry change.
- **`--check` is the snapshot gate:** a golden image is only as good as what it proves; the four
  in-image probes and the three profile keys now fail the check instead of surfacing at 09:15 on a
  fresh VM.
- **Mutation lesson repeated:** the second substring-weak assertion this wave (see CHG-367 M1) —
  both were only found by running the mutation, which is why the mutation step is mandatory.
