# CHG-360 — day runner: readiness-only probe + streaming log readers (memory)

- **Status:** complete — the wait loop no longer runs the full collector every
  5 s, and the log readers stream line by line with a bounded hit count, so a
  noisy Fluss recovery can no longer balloon the runner's memory.
- **Filed:** 2026-09-28
- **Source:** incident during the F8 cold-start drill: the runner reached
  **12.3 GB RSS + 16.3 GB swap** while the tablet was recovering for 36 minutes
  and thrashed the host (the drill had to be stopped).
