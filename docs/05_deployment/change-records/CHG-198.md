# CHG-198 — short phases skip the injection loudly; the smoke gate tells "skipped on purpose" from "broken"

- **Status:** recorded — fixed and guarded (2026-09-17)
- **Filed:** 2026-09-17
- **Source:** the sub-40s leftover of the wave-36 plan
  (`docs/plans/2026-09-16-wave36-holistic-measure-repair.md`, Task 5): any phase
  of 40 s or less failed outright with "too short to host an injection".

## What happened

The inject offset is clamped into the sampled window with a 20 s margin (15 s
candle window + one poll sample — physics, not tunable), so a phase of
`duration_s <= 2 * margin` cannot host an injection. The harness answered that
with `fail()`, which forbids short pipeline-sanity iterations outright. The
margin cannot shrink to fit, but nothing else required the failure: the smoke
gate already sums its want from `faketool.log` (no INJECT line sums to zero),
and faketool fires no round on zero counts (`main.go`: `injectAfter>0 AND
(dups>0 OR late>0)`). Testing the change exposed two further blockers in the
same path (both fixed below): the gate *failed closed* on a missing injection
with no "skipped on purpose" distinction, and its want-derivation died
*silently* (`set -e` + `pipefail` + matchless grep) before ever reaching that
branch.

## What changed

- `code/01_platform/04_scripts/holistic-measure.sh` —
  (a) the `|| fail` became a skip branch: phases at or under twice the margin
  print `INJECT SKIPPED: this phase proves nothing about duplicate/late
  handling`, unset `INJECT_AFTER_MS`/`INJECT_MAX_ROUNDS`, export
  `INJECT_DUPS=0 INJECT_LATE=0`, and write `$OUT/inject-skipped` (reason +
  durations). Phases above the margin are byte-identical in behavior (180 s
  still 120000, 60 s still 85000 — the existing pins hold).
  (b) `smoke_inject_gate` checks the marker FIRST: present → loud
  `GATE SKIP` pass (return 0, other gates still apply); absent + no INJECT
  lines → the pre-existing loud fail-closed branch (unchanged). A lost marker
  therefore fails loudly, never silently — the self-check on the write.
  (c) the want-derivation carries `|| true`: with `pipefail` a matchless grep
  (or missing log) returned 1 inside the command substitution and `set -e`
  killed the caller with no message; want=0 now reaches the loud branch.
- `code/01_platform/04_scripts/tests/test_holistic_measure_wave36.py` —
  `test_a_phase_too_short_to_host_an_injection_is_rejected` rewritten as
  `test_a_phase_too_short_to_host_an_injection_skips_loudly` (notice +
  `OFFSET=unset` + `PHASE_RC=0`); new
  `test_a_skipped_injection_passes_the_gate_with_a_loud_notice` (marker →
  `GATE SKIP` + `GATE_RC=0`) and
  `test_a_missing_injection_without_the_marker_still_fails_closed` (no marker
  → `no INJECT lines` + `GATE_RC=1`).
- Deliberately **not** changed: the analyzer. A skipped main phase runs its
  pre-existing parity-only audit, and the 20 s margin value itself.

## Known limitation

A skipped MAIN still runs the analyzer's parity-only audit with its
clean-feed assertions (`late_rows == 0`): natural feed re-feeds (CHG-192 —
measured 114 on one subtask in run 9, 317 across two in run 12's smoke) can
fail it. That is the pre-existing, deliberate behavior for every
injection-less run (TM-kill drills included), not something this change
introduces — the short-smoke use case this change enables never reaches the
analyzer's main-phase audit.
