## What changed

- New `fillBookAndStats(frame, ltp, tok)` in `faketool/main.go` writes the
  full-frame section the real feeds populate: vwap/day OHLC/prev-close,
  circuit limits, total buy/sell quantity, 5x bid/ask price/qty/orders,
  open interest, atv/btv — at the exact offsets
  `cmd/gen-corpus/buildFullFrame` uses (and the golden corpus verifies
  against the bridge decoder).
- Wired into all three frame paths: the real-rate ticker (used by the
  loadtest / E2E harnesses), the snapshot burst template, and the
  tick-interval ticker.
- No production file changed. `faketool` is excluded from the production
  bridge build by its build tag.

## Why

The compute market snapshot's presence gates read the raw tick's stats clock
and each level's price (`MarketView::hasStats`, `bidPx > 0`). The fake feed
sent only `ltp`/`ltq`/`volume`, so a fake-broker run produced sealed rows with
only `last_price` and could never demonstrate the 42 market features end to
end. With this change the standard fake-broker smoke writes every timeframe's
sealed row with the full stats + depth bag.
