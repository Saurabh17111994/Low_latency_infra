## What changed

- `RawTableColumns`: named reader constants for the 16 raw extras (day OHLC/VWAP,
  TBQ/TSQ, OI + OI day range, level-1 bid/ask, circuit limits), each pinned to its
  DDL name at class load.
- `MultiTimeframeState`: the dormant quote snapshot became the market snapshot —
  the 4 level-1 quote fields reused, 12 new fields for day stats/OI/limits, all
  initialized to 0 ("not yet seen"); none are cleared by `resetForming`
  (P2-152 contract extended).
- `MultiTimeframeAggregateFunction`: `updateMarketSnapshot` runs on every accepted
  tick (trade **and** quote, before the quote early-return); latest non-null wins
  per field. `buildLiveRow` appends the 16 values to every forming row on both
  feeds (fast per-tick and the 1 s mirror fallback), NULL when never seen.
- `CandleLiveColumns`: trailing transport-only market section (indexes 16–31,
  BIGINT NULL) after the `ingest_ts` probe; the pinned 15-column DDL prefix and
  `ingest_ts` position are unchanged.
- Strategies read the values from the `live` row via `CandleLiveColumns.MKT_*`
  in `onLiveTick`; no `SignalStrategy` signature change, no host change, no DDL,
  nothing new persisted.
