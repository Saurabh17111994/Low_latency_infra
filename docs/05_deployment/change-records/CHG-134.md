# CHG-134 — Pre-warm budget check stops failing on a single host tail sample

- **Status:** recorded — what the gateway suite's C1 check asserts changed (a certifying assertion)
- **Filed:** 2026-09-14
- **Source:** the 19-step certifying run of 2026-09-14 15:01 failed at step 14 on one sample

## What happened

`GatewayStartupPrewarmTest.firstWriteAfterPrewarmStaysWithinRequestBudget` timed eight post-pre-warm
projection writes and required **all** of them to be under the caller's 2000 ms bound. A certifying gate
run failed with samples `[200, 167, 13, 255, 2219, 266, 147, 14]` — one outlier, its neighbours normal.

The measurement behind the change (2026-09-14, this host):

| Run | p50 | max |
|---|---|---|
| gate 133943 | 33ms | 118ms |
| gate 135737 | 188ms | 367ms |
| gate 150141 (**failed**) | 200ms | **2219ms** — one sample, 7 normal |
| 6 isolated repeats | 31–128ms | 138 / 226 / 350 / 482 / **1033** / 145ms |

So the tail of *clean* runs already reaches 1033 ms: the bound sits barely 2× above ordinary host noise,
and the assertion failed on scheduler stall rather than on the property it exists to check. The property
is unambiguous in the same data — p50 13–128 ms, i.e. pre-warm consumes the post-CREATE window.

## What changed

`prewarmWindowResidual(samplesAtOrOverBound)` now decides: **two or more** samples at or over the bound
fail; one is tolerated and logged. The discriminator is the regressions's own signature — each iteration
opens a fresh database, so pre-warm that stopped working pays the window in every iteration (~8/8), not
once in eight. A new cluster-free test pins both branches, including the real failing sample list.

Not weakened: the production bound (2000 ms) and the production assertion that drove the change
(`cfg.requestTimeout() == 2000`) are untouched, the sample list and count are still printed into the
certificate log, and a tolerated outlier is called out by its own NOTE line.

## Why it is recorded

Step 14 gates the certificate, so changing what it tolerates changes what "19/19" means. The record
exists so that a later reader sees the tolerance, the evidence for it, and the fact that a single slow
sample is reported rather than hidden.
