## What changed

- `SignalJobOperatorUidTest.env()` no longer sets `ALLOW_FULL_REPLAY=true`;
  `SignalJobConfig` defaults to `StartupMode.LATEST`, so
  `rawSourceOffsets` returns `OffsetsInitializer.latest()` instead of
  `OffsetsInitializer.full()`.

## Why

- The live `default.raw_table_1` is datalake-enabled (`table.datalake.enabled =
  true`; `TableInfoDump` probe 2026-10-02 — the DEC-060 r2-archive-sync opt-in,
  while the DDL default stays false).
- Fluss's `FlussSourceBuilder.build` calls `LakeSourceUtils.createLakeSource`
  only when `TableConfig.isDataLakeEnabled()` **and** the offsets initializer is
  a `SnapshotOffsetsInitializer` (bytecode-verified; `OffsetsInitializer.full()`
  is one).
- The test JVM has no `fluss-lake-iceberg.jar` (the cluster containers mount it;
  it is not a compute test dependency), so the FULL-replay build failed with
  `UnsupportedOperationException`.
- The UID pin is startup-mode independent: production fresh-submits at LATEST
  and restores from checkpoint offsets; FULL replay is the A3.4 break-glass mode
  whose offset semantics are unit-pinned by `RawSourceOffsetSelectionTest`.
  `B4SignalIntentE2ETest` already builds the topology at LATEST and passed.

## Verification

- Failing-first (gate evidence): `compute-uid-pin.log` of
  `monday-gates-20261002-150309` — 5 errors, all
  `No LakeStoragePlugin available ... ensure fluss-lake-iceberg.jar is in the
  classpath`.
- Root cause: `TableInfoDump` dump of `default.raw_table_1` shows
  `table.datalake.enabled = true`; `javap` of `FlussSourceBuilder.build` shows
  the `isDataLakeEnabled() && SnapshotOffsetsInitializer` gate before
  `createLakeSource`.
- Smoke: the exact gate invocation
  (`COMPUTE_INT_TEST_P6=true FLUSS_BOOTSTRAP=localhost:9123 mvn -o test
  -Pdrill-reports -Dtest=SignalJobOperatorUidTest,TradeDecisionsSinksUidTest`)
  → `Tests run: 8, Failures: 0, Errors: 0`, `BUILD SUCCESS`.
- Full gate run to certify this commit (evidence under `logs/soak/`).

## Residuals

- No test now builds the FULL-replay lake-augmented source graph; the replay
  offset selection stays unit-pinned, and the cluster containers (which mount
  the plugin) exercise the real lake path. A future test that needs the lake
  source must add the plugin to its classpath explicitly.
