## What changed

- `StrategyHostFunction`: FEATURE_ROWS side output, `featureRowsEnabled`
  constructor parameter, `emitFeatureRow`, its counters and heap mirrors, and
  the test accessor are gone. Feature computation itself is untouched (the
  merged row consumes the same snapshots).
- `SignalJob`: the gated feature-values sink and the feature preflight block
  are gone; the host is constructed with two arguments again.
- `SignalJobConfig`: `FEATURE_LAYER_ENABLED` / `FEATURE_TABLE` components,
  parsing, validation and getters are gone.
- `TableContractValidator`: `validateFeatureValuesTable` + its contract id are
  gone; the merged validator (W-C3) is the only candle-feature contract.
- Deliberately left for W-C5a (ops surface): `docker-compose.yml`/`.env`
  entries, rollout env lists, `feature-values-table.sh` + its Python runner,
  the ingestion registry entry, DDL 34 and the docs/probes that mention them.
