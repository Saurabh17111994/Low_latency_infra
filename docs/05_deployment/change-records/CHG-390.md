## Notes

- **One dial, verified by construction:** `build_session_client` creates the only transport;
  `SessionHandle` is cloned into the forwarder and the factory, and `ensure_open` dials once
  (CHG-389's `one_dial_for_route_and_node` pins it).
- **Registry writers:** the route writes before `send_command` (a postback cannot race an
  unregistered ref); the node writes in `build_order_envelope` next to its own `client_refs`.
- **Halt fan-out:** the dispatcher's Send halt seam and the node's `HaltNotifier` both bind to
  `ServerState::safety_halt`, so an unknown ref stops the served forward leg exactly like a
  node-side ambiguity.
- **Pre-existing flake observed (not this change):** `clockwatch::tests::the_live_source_measures_a_real_process`
  failed once in four full-suite runs with `ETXTBSY` (a concurrent `fork` in another test thread
  inherits the stub script's write descriptor). Evidence kept in
  `logs/chg-390/cargo-test-flake-observed.txt`; it passed on every re-run.
