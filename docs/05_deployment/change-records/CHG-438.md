## Notes

- **Why not `PYTHONDONTWRITEBYTECODE=1`:** that stops *writing* caches but Python still *reads* any valid `__pycache__` entry — a pre-existing poisoned cache would keep lying. Removing the caches before the suites is what makes the imports source-faithful; the sweep costs milliseconds across 9 dirs.
- **The sweep is step-3-scoped on purpose:** step 3 is where the suites import repo modules (`sys.path.insert` on `04_scripts`). Earlier steps run scripts as `__main__` (no cache read) or bash; later steps import nothing new, and the gate rule forbids source edits mid-run.
- **Prevention, not a workaround:** the poisoned cache was an artifact of the mutation-check workflow this repo mandates; sweeping at the certifier removes the class instead of relying on wall-clock luck between an edit and an import.
