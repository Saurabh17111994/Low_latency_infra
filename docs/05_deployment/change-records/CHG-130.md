# CHG-130 — Retired Python execution scaffold deleted (five P3 findings disposed)

- **Status:** recorded — code removed, no contract or gate behavior changed
- **Filed:** 2026-09-14
- **Source:** wave-4 P3 remediation, batch B7 (legacy_python disposition)

## What changed

`legacy_python/` — the pre-Rust execution-service scaffold (Dockerfile, `main.py` whose entry
point raises `NotImplementedError`, `requirements.txt`) — was deleted. CHG-048 had already
retired it in favour of the Rust service; `main.py` was not runnable as a trading path and
nothing in the tree built, imported, deployed or tested it.

Deleting it is the disposition for the five findings filed against those files, because each is
moot once the file is gone and none is worth fixing in a fallback nobody runs:

| finding | what it was | why deletion is the resolution |
|---|---|---|
| P3-177 | `PYTHONUNBUFFERED` unset, so print-based logs could be lost on crash | the file with the print statements is gone |
| P3-178 | `COPY . .` with no `.dockerignore`, baking the whole build context into the image | the image is no longer built |
| P3-179 | the container ran as root | same |
| P3-416 | `ARROW_APP_ID` / `ARROW_TOKEN` read but never referenced (dead config) | the config reads are gone with the file |
| P3-417 | every setting, including `EXECUTION_ENABLED`, evaluated at import time | there is no module to import |
