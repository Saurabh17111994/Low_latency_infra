## Notes

- **Why the recheck sits inside the send lock and before the claim:** the route's pre-check cannot
  be atomic with the send, and a claim that precedes a refusal would leave a `SUBMITTING` attempt
  for an order the bridge never saw — the exact ambiguity the attempt protocol exists to avoid.
  The claim's file append now happens under the forwarder lock; the gateway event emission after
  the send remains outside it (it must not stall concurrent submits).
- **Term checks only when hydrated:** before the durable boot row is adopted the local epoch is not
  the durable generation, so enforcing it would refuse legitimate orders. Flag-off/paper runs have
  no partition and are unhydrated, so their behavior is unchanged.
- **The deck drift was dormant:** the stack's executor was pinned to `dev-partition` while its
  gateway defaulted to `prod-partition`; nothing enforced the value for orders before M1-1 (only
  the H2-5 gate report, which no deck has enabled), so the mismatch would have appeared as
  every-order-refused the day execution was turned on. CHG-336's own record claimed the values
  matched; the alignment test now makes that claim executable.
- **No denial of service:** a foreign partition is a routing/config error, so it is counted and
  refused without touching the gate; only evidence that *our* generation is stale (epoch/fence/
  lease) halts.
