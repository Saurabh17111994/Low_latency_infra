## Why

`make docs-audit` runs four checks — clippy, `cargo fmt --check`, `go vet` and the docs audit — and fails if
any of them fails. `cargo fmt --check` was failing on this file, so the target could not pass.

## What changed

`cargo fmt` rewrapped statements in the test module. All four hunks are inside `#[cfg(test)] mod tests`
(the diff headers read `@@ ... @@ mod tests`), and they are line breaks inside `insert` and `assert` calls.
The token stream is identical; `cargo fmt --check` is clean.

## What this does not change

No production code, no test behaviour, no assertion, no fixture and no expectation. The affected tests still
assert exactly what they asserted before — the same file-wins, missing-file, empty-file and precedence cases
for the gateway secret file.
