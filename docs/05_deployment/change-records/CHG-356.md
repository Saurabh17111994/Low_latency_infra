# CHG-356 — F2: cold-start write grace is the whole window; startup budgets 3600 s

- **Status:** complete — the zero-ack watchdog stands down for the whole
  bounded write-path startup grace (an early ack no longer re-arms it), and
  both startup budgets cover the measured cold-start recovery (default
  3,600,000 ms; operator range to 7,200,000 ms).
- **Filed:** 2026-09-28
- **Source:** P4-4 first-morning validation (finding F2): the 2026-09-28 cold
  start killed a healthy ingestion container ~1 min in (reproduced in
  `logs/chg-356/repro-ingestion-log.txt`); the off-hours drill then measured the
  tablet's real recovery at 22 min 56 s and showed the interim 900 s budget fails.
