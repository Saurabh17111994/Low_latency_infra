## What changed

- `SignalJobConfig`: two record components -- `candleContextTable`
  (`CANDLE_CONTEXT_TABLE`, default `candle_closed`, blank falls back) and
  `candleContextSealedOnly` (`CANDLE_CONTEXT_SEALED_ONLY`, default false).
- `FlussCandleFetcher`: `open()` resolves `config.candleContextTable()`; the
  3-arg constructor carries `sealedOnly`; `decode(result, key, sealedOnly)`
  keeps the DDL 33/35 15-column prefix decode, rejects a key mismatch, and in
  sealed-only mode returns `null` for `sealed=false` and for a row without the
  sealed column (warning + fail-closed, never a throw). The provider's
  absence cooldown retries, so a forming window is served once it seals.
