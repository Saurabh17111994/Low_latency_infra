## What changed

- **`MergedCandleRow`** (new record): the merged table's 17 fields —
  `candle_closed`'s 15 columns + `features Map<Integer, Double>` + `sealed` —
  with a defensive `Map.copyOf` in the compact constructor, `forming(...)` /
  `sealed(...)` factories over a `ClosedCandle`, and the single writer rule
  `acceptsUpdate(existingSealed) == !existingSealed` (a late tick can never
  rewrite a sealed window; DEC-059).
- **`SignalJobConfig`**: `MERGED_CANDLE_FEATURES_ENABLED` (default **false**,
  `booleanValue`), record field + accessor + javadoc. With the flag off every
  future runtime path is inert and the existing candle/feature tables stay
  authoritative.
