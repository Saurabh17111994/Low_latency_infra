## Notes

- The image is built from **one repo commit + one image set**; rebuild
  (`§2.2–2.5`) whenever code or images change, and version the image name by
  date (e.g. `trading-golden-20260928`).
- The golden image deliberately contains **no secrets**; `secrets.env` is
  injected on each daily VM (so an image leak is not a credential leak, and
  rotation needs no rebuild).
- The image set transfer is a streaming pipe (`docker save | zstd | ssh |
  docker load`): nothing lands on the dev PC's disk, and the VM needs only
  Docker + zstd.
