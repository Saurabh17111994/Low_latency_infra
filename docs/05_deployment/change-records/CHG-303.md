# CHG-303 - the 2026-09-03 dedup redesign had no change record; this files it with the doc correction

## Summary

`c0c50ee6` (2026-09-03) replaced the Design-B fingerprint dedup - a Flink `MapState` with native
`StateTtlConfig` expiry - with an **operator-local bounded count window**: `FingerprintDedupFunction`,
operator uid `fingerprint-dedup-v2`, `DEDUP_WINDOW_ENTRIES` = 200 entries per token held as plain
fields and **intentionally not checkpointed**. No change record was filed for it, and every document
describing the dedup contract kept describing the retired design as current.

This record files the change that already happened and the correction of the documents that
described it wrongly. No runtime behaviour changes: the code is untouched and the correction is
documentation plus this record. The record is late because the change shipped without one and its
redesign plan (`docs/plans/2026-09-03-dedup-redesign-plan.md`) was deleted by `2a8fdf91`, citing an
evidence directory (`stage-a2-baseline-20260903-193144`) that exists nowhere in the repository. The
stale integration test that still asserted the Design-B invariant survived because it is
environment-gated and never runs in the platform suite; it was found on 2026-09-23 and re-scoped to
the heap-window contract.
