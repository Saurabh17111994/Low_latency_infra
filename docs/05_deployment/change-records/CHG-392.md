## Notes

- **Why retire rather than repoint:** the rules watched `compute.signal.active.count` /
  `compute.signal.dropped.active.exists` (producers deleted with the active-signal subsystem) and
  `trading_alerts` admin-clear events (same subsystem). A `gate_safety_halt` substitute would be a
  second dead rule: the executor's OTLP sink is a NullSink today. The runbook records that
  dependency as the trigger for a future rule.
- **The guard is an existence probe, not an emitter proof:** a name mentioned only inside an
  inline test module still counts as present. It closes the measured failure class (a rule whose
  producer was deleted wholesale) offline, with no broker.
- **C19's count:** the dossier's "provisions 47 rules" sentence was always counted against
  `o2-provision.py` alone; the retired corpus was the extra 3 in the union. The union now equals
  that 47, so the sentence is unchanged and C19 reports 47.
