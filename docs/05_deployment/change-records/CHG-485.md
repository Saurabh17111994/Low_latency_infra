## Notes

- **Double-count guard.** A forming candle previews only strictly above the
  newest closed window (`lastClosedWindowStart`), so the window that just
  closed is never counted twice: once the close lands, `latestLive` returns the
  closed value.
- **Preview semantics.** `latestLive` is pure arithmetic over the computer's
  closed accumulators plus the forming close; the closed snapshot stored in
  `candle_features` keeps the closed-candle values only (no preview ever lands
  in the feature map).
- **Canonical tick rule unchanged (L3-4).** Only the FIFTEEN_S forming row
  updates the timeframe-independent TICK features; every other TF's forming row
  still records its own evolving candle and fans out to strategies.
- The fix to `TICK_COUNT` reading is included here because it belongs to the
  forming-candle path introduced by this change; without it the new tests and
  the pre-existing tick-feature assertions fail.
