## Why

The plan's D3 decision was always "tag `v*` plus manual dispatch", and its dated note deferred the tag half
with a stated condition: *"The tag trigger returns once the commit-back path has been proven by a dispatch run
on the default branch."* Run `35567002862` met that condition — 13/13 steps, fragment committed as `24a061ad`.

The reason it needed a condition at all still holds: this workflow always checks out the **default branch**
and commits the digest fragment back to it, because a digest that lives only in a run log is not durable. So a
tag cannot select a revision here — it can only name what is about to be published. Without a guard, a tag
left on an older commit would publish the default branch tip and record digests labelled with a version they
do not describe.

## What changed

- `on:` gains `push: tags: ['v*']` beside `workflow_dispatch`.
- A new step, immediately after the checkout and only on a tag push, runs `publish-tag-guard.sh <tag>`.
- `publish-tag-guard.sh` (new) resolves the tag **inside the checkout** and fails the run unless it points at
  `HEAD`. It peels an annotated tag with `^{commit}` — a tag object has its own sha, and comparing that to
  `HEAD` would refuse a perfectly good tag — and it fetches the tag when the clone does not have it, which is
  the normal case because `actions/checkout` does not fetch tags.
- It deliberately never reads `github.sha`: this repo has not measured what GitHub puts there for a tag push,
  and the guard does not need to know.

## What this does not change

The manual path is untouched. The checkout still pins the default branch, the fragment still commits back to
it, no secret is added and no PAT appears — the trigger is the only new input.

## Not verified

The trigger itself. A `push: tags` event only exists on GitHub, so the wiring is asserted by parsing the
workflow, not by a real tag push. The first `git push origin <tag>` whose tip matches the default branch is
that proof, and it will publish the seven images again (it also spends a full run).
