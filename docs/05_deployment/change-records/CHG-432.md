## Notes

- **The README is contract surface:** it is what an operator reads before dropping a manifest in, and every
  wrong claim in it was a plausible-sounding instruction that would waste a real run (looking for a fixture
  that does not exist, setting a key no process reads). The guard treats it like the compose/stack files.
- **The dead plural is not even spelled:** the repo convention (compose/stack comments) is to describe the
  removed key without printing the literal, because the literal one letter from the live singular is what
  drifts back. The README follows it, and the guard fails on the literal in either file.
- **Links are checked by resolution, not by inspection:** the test resolves every markdown target relative to
  the README or the repo root, so a future rename of the loader class or the split helper fails the gate
  instead of leaving a 404 in operator docs.
- **The old requirement link survives:** `/docs/02_requirements/02-functional/01-ingestion.md` exists and is
  kept; the deleted `/docs/09_data_gaps.md` link had no replacement file (there is no `docs/09` tree), so the
  DATA-GAP-001 reference is dropped rather than re-pointed.
