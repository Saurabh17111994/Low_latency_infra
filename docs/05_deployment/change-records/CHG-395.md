## Notes

- **Why the pair is symmetric:** `ACCOUNT_SCOPE_ID` was only ever read by the durable reporter,
  and the reporter needs the partition to own a row — so "scope without partition" is as
  unusable as "partition without scope", and refusing both shapes at boot keeps one rule:
  identity halves are set together or not at all.
- **Why the keeper stops rather than retries:** a 409 `SCOPE_MISMATCH` is an operator
  configuration error; the locked-gateway posture (retry with backoff) made the two
  indistinguishable and hid the misconfiguration for hours. The ERROR names both keys and the
  readiness gate stays `durable_gate=false`, which is what an operator already watches.
- **Wire compatibility:** `approve`/`halt`/`renew` still return `Result<GateAck, String>`
  (Display of the typed error), so the HTTP handlers and their tests are unchanged.
