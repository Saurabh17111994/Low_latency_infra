## Notes

- **Why the pin:** the selector existed since 2026-09-24 but only in the gitignored host `.env`.
  `docker-stack.yml` had no `ARROW_FEED` at all (Swarm ignores `env_file` → the deck ran the code
  default `hft`, dead on this account), and the daily VM profile/runner did not pin it either.
- **Both channels stay selectable:** `ARROW_FEED=hft` is the only change needed to switch back;
  the Go selector test table and the Java label gate stay.
- **Fake brokers are unaffected:** `streamFactoryFor` checks `ARROW_HFT_URL` before the channel
  selector, so every resilience ladder and the stage profiler's fake branch keep their socket.
- **Contract currency:** `01-ingestion.md` was updated where it still described NDJSON transport
  and the "Standard feed removed 2026-08-14" state — the live contract now names the proto
  transport and both selectable feeds.
