## Notes

- **Why the wave tests missed it:** L2-1's own guard (test_static_check_scope.py) covers the enumeration itself, and
  L6-1's covers the infra files — neither runs the *harness* guards (wave21/wave25) or the tools that render
  compose. Only the aggregated step-3 run sees all callers; that is exactly what the pre-gate smoke is for, and
  it is why the smoke runs before the certifying gate.
- **The compose-form guard had a blind spot:** it scans shell-form invocations (backslash-joined), so Python list
  literals were invisible — t9's bare render survived the guard, L2-1's wave and the docs audit, and only failed
  when compose interpolation gained the O2 guard. The AST check closes the shape, not just the one site.
- **Evidence separation kept:** the enumeration diagnostic still lands in STATIC_LOG (it is a static-check
  failure) via an explicit FAIL block; the wave21 rule against bare redirections into the step log stays intact
  and the comment avoids quoting the forbidden token so the line-based guard reads it correctly.
- **The disaster-drills literals were not dead code:** the runner executes `fault`/`recovery` steps directly
  (`run(step)`), so nine drill steps would have failed their first real run after L6-1. They now share
  `compose_cmd()` with the tool's own `compose()` helper.
