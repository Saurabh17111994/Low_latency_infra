## Notes

- **Measured before the fix:** the overlay had 5 services; the base compose publishes 8 (otel, O2 and
  MinIO were the gap), so a p10 rehearsal next to live failed to bind. FACT-017 recorded the same
  collision class for base-vs-deck.
- **Why 1xxxx:** the band is deliberately outside every base and deck port (all < 10000), so the guard
  can assert disjointness cheaply and a future base port cannot silently re-collide.
- **FACT-017 superseded, not edited:** the base-vs-deck O2 5080 collision is still true and is carried
  in FACT-023's claim; what changed is the "no overlay remaps either" clause. LIVE rows are never
  edited in place.
- **Pre-existing drift noted:** `env_facts.py check` also reports FACT-007 and FACT-016 as DRIFT —
  live-cluster checks against running containers on this host, unrelated to this change.
