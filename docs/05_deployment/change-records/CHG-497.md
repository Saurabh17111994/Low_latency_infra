## Why

The compose base publishes nine host ports on all interfaces (`8081`, `9249`, `9250`, `4317`,
`4318`, `5080`, `5081`, `9000`, `9001`) and the daily VM is created on a public network, but the
guide had no firewall/security-group/tunnel step (the 4-VM guide mandates one).

## What changed

- §2.1: VM creation requires a CloudPe security group allowing only SSH (`22/tcp`) from the
  operator's IP — CloudPe's default group allows everything.
- §3 step 1: names the nine ports, states they bind on all interfaces and must stay closed at
  the provider firewall; UIs are reached only through `ssh -L` tunnels.
- §6: new failure row for a publicly reachable port.
