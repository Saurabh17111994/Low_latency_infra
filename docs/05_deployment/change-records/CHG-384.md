## Notes

- **Why the exact check was deleted:** it had zero call sites; the live requirement is parse +
  minimum. The version stays a loader parameter (R-247) and the fingerprint remains an identity
  signal (the token-hash cross-check), not an approval match.
- **Why 1024:** the approved production manifest is 1024 rows; the daily VM's full universe is 2433
  rows. Both pass 1024; a truncated CSV does not.
- **The Python guard is the permanent pin:** it fails if the dead check returns, the startup gate is
  dropped, or any profile pin is lost.
