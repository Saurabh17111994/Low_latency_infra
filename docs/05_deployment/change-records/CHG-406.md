## Notes

- **Zero writes on an unreadable list:** the old code turned a 500 body into `set()` and POSTed
  every alert/destination again — on a healthy stack that is at best noise, on a half-read one it
  is a duplicate-write race.
- **Deferred ≠ failed:** an alert whose metric stream does not exist yet (off-session compute) is a
  known posture; it is counted and printed as deferred so a live run can tell the two apart.
- **`main(argv)` is the test seam:** the health-gate and `--check` paths now return instead of
  `sys.exit`, so callers (and tests) can assert the int.
