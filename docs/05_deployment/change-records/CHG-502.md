## What changed

- **`MarketView` (new)** — the strategy-facing read API: presence
  (`hasStats`/`hasDepth`/`hasLevel`), the 42 named getters, derived values
  (`spreadPaise`, `totalBidQty`, `totalAskQty`, `depthImbalance` NaN-when-empty,
  `micropricePaise` size-weighted half-up), the real-ladder walks
  `walkAvgPricePaise`/`slippagePaise` (adverse cost ≥ 0; `INSUFFICIENT_DEPTH`
  when the book cannot fill), and freshness (`statsAgeMs`, `depthAgeMs`,
  `ageMs`, `isStale`; never-seen = `Long.MAX_VALUE`). 0 = not provided.
- **`MarketSnapshot` (new)** — public-field POJO implementing `MarketView`
  (12 stats + 30 depth + 2 clocks); the single storage type used by both the
  aggregator state and the host slot, so no field list is duplicated.
- **`StrategyView` (new)** — `market()` + `features()` + `context()`; one
  stable instance per host slot, never null.
- **`SignalStrategy`** — three new default overloads taking `StrategyView`
  (`onLiveTick`, `onClosedCandle`, `onContextReady`); each delegates to the
  pre-view form, so N7/stub-smoke and every existing strategy are unchanged.
  The closed path now sees the latest market snapshot (it previously saw none).
- **`MultiTimeframeState`** — the 16 flat market fields were replaced by one
  nested `MarketSnapshot market` (POJO-safe; still survives `resetForming`).
- **`MultiTimeframeAggregateFunction`** — `updateMarketSnapshot` reads all 42
  raw columns per accepted tick (trade or quote), latest non-null wins, and
  advances `statsChangedAt`/`depthChangedAt` only when a value of that group
  actually changes. `buildLiveRow` writes the 44-column section **only on the
  `FIFTEEN_S` row** (one row per tick instead of six: ≈352 B/tick vs ≈2.1 KB/tick
  at 60k ticks/s); the other five rows stay all-NULL.
- **`CandleLiveColumns`** — market section is now 44 columns (indexes 16–59):
  12 stats, then the 30 depth values in raw attribute-major order, then the two
  clocks; `FIELD_COUNT` 32 → 60. Still transport-only, BIGINT NULL, absent
  from every DDL, after the unchanged `ingest_ts` probe.
- **`RawTableColumns`** — 26 new reader constants for depth levels 2–5 and the
  order counts (indexes 31–60), each pinned to its DDL name at class load.
- **`StrategyHostFunction`** — decodes the canonical row into the slot's
  `MarketSnapshot` (`decodeMarketSnapshot`, NULL → 0; non-canonical rows never
  touch it) and hands `slot.view` to all three strategy callbacks.
