## Notes

- **The verdict is the certificate:** it printed "N/19 verified" while subtracting only the skips
  that called `note_skip`. A step skipped by a bare WARN was counted as verified — the same class
  as a test that never runs.
- **The allow-listed exception is real:** without shellcheck installed, step 1 still runs `bash -n`
  on every script, so it is partial verification. The static invariant matches it by message, not
  by line number, so it cannot silently cover a new skip WARN.
- **Shellcheck directive trap:** the first comment draft began a line with `# shellcheck-absent…`,
  which shellcheck parses as a malformed directive (SC1073); the comment was reworded so step 1's
  own shellcheck gate stays clean.
