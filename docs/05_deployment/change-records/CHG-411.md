- **The finding was a three-way disagreement:** the writer constant (`SCHEMA_VERSION_V2 = "2"`,

  DDL 05's header carried the *table-kind* number (3 — LOG→KV→LOG history) as if it were the row
  contract, DDL 23 said 1, and the manifest copied both.

  untouched — the new header note makes the distinction explicit so the next editor does not
  "fix" it back.

  prints "DDL NOT APPLIED" and the DDL corpus remains a reconciled proposal (AGENTS.md hazard).

  the drift from H3-3's DDL edit; M6-1 will regenerate once more for its own header fix.
