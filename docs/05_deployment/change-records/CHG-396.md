## Notes

- **Why `|| true` and not `|| echo 0`:** `grep -c` prints `0` **and exits 1** on zero hits; the
  fallback appended a second zero and the numeric test saw `0\n0`. `|| true` swallows only the
  status, so the count survives as a single value.
- **Why the evidence file is asserted before anything is read:** without it, a missing log and a
  low count produced the same verdict — the recipe could print a certificate for a run whose
  evidence never existed.
