## Notes

- **Why the Dockerfile change is part of the flip:** the executor runs as `nobody`; without the
  image-owned mount point, enabling the flag turns every boot into a fail-closed EACCES. The
  guard test pins the ordering (mkdir+chown before `USER nobody`), because a comment would not.
- **The window:** execution stays halted (`EXECUTION_ENABLED=false` in the stack, default false in
  compose), so the flip changes what a *permitted* order does, not whether orders are permitted.
- **Deploy status:** production deploy remains unproven from this host (FACT-001/FACT-012); this
  change is certified by static render + the gate-discovered test, not by a live deploy.
