## What changed

1. **Core (`r2_archive_selection.enabled_outside`)**: the guard-side rule —
   live-enabled tables the list does not allow; an empty `selected` is legal
   here (it means "nothing may be archived"). `plan()` now computes `disable`
   through it, so the sync and the guard share one rule body.
2. **Preflight (`gate_preflight.py`)**: a new check (item 8 in the module
   docstring) —
   - `table_archive_flags()` reads every live table's `table.datalake.enabled`
     from ZK via the existing `docker exec zookeeper zkCli` pattern (no JVM /
     class files needed, so it works before any build);
   - `archive_selection_drift(live, EOD_TABLES)` is pure and fail-closed:
     unreadable flags, or any enabled table outside the list, or any enabled
     table while no list is configured, are drift;
   - a PASS prints `OK archive selection: N of M tables enabled, ...`.
