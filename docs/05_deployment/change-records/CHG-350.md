## What changed

| Site | Change |
|---|---|
| `SignalJobConfig` | `FEATURE_LAYER_ENABLED` (default false, requires `STRATEGY_HOST_ENABLED=true`) + `FEATURE_TABLE` (default `feature_values`, non-blank), accessors `featureLayerEnabled()` / `featureTable()`. |
| `SignalJob` | Host branch keeps a `SingleOutputStreamOperator` reference; when enabled, `FEATURE_ROWS` → `FlussSink` (`RowDataSerializationSchema`, same timeout/retry options as candle sinks), `.name("feature-values-sink").uid("feature-values-sink-v1")`. Preflight validates the table contract when enabled. |
| `TableContractValidator` | `validateFeatureValuesTable`: exact PK `(instrument_token, tf, window_start)`, 4-column schema with `MAP` features, 16 buckets routed by `instrument_token`. |
| Compose / `.env` | Anchor keys `FEATURE_LAYER_ENABLED: ${FEATURE_LAYER_ENABLED:-false}` + `FEATURE_TABLE: ${FEATURE_TABLE:-feature_values}`; dev `.env` keeps the layer OFF until the table exists. |
| Rollout | `rollout-savepoint.sh` `JOB_ENV_NAMES` + `pipeline-lib.sh` submit forward both keys; static pin added. |
| Docs | Storage contract table inventory gains `feature_values` (marked proposal/not applied); dossier feature-layer subsection gains the S3 facts. |
