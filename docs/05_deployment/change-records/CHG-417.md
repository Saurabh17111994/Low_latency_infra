## Notes

- **Why the test was red and nobody saw it:** M2-1 was verified with the scoped M2 suites; this
  file belongs to the F7 disk-safety region and only runs in the full Python suite (gate step 3).
  The full suite is what caught it, exactly as intended.
- **Why the test changed, not the recipe:** one entry point is M2-1's design (a fresh VM without
  `O2_AUTH_BASIC` used to exit 2 from the first command and run blind). Reverting the recipe to
  two commands would undo that fix; the guard follows the contract.
- **The mutation that taught the shape:** asserting the bare names passed even with the calls
  removed, because the wrapper's comment names both tools. The assertion is now the invocation
  line — a name in a comment proves nothing.
