## Why (audit-verified)

- **H6:** `run-ingestion-full.sh` never set `ARROW_FEED`; the Go bridge defaults to HFT
  (`supervisor.go`), which the broker rejects since 2026-09-24 (`PLAN_NOT_SUBSCRIBED`). The
  documented host start path ingested nothing. Compose already defaulted `token`.
- **H7:** `docker-compose.soak.yml:82` hardcoded this PC's manifest source with no override.
- **H8:** `ManifestLoadTest.loadProductionManifest` read `/home/saurabh/...` directly while the
  Monday gate forces `INGESTION_INT_TEST_MANIFEST=true` (`run-monday-gates.sh:873`), so the
  gate could not pass on any other machine.

## What changed

| File | Change |
|---|---|
| `code/run-ingestion-full.sh` | `export ARROW_FEED="${ARROW_FEED:-token}"` with the HFT-removal rationale — mirrors compose |
| `docker-compose.soak.yml` | manifest bind source `source: ${SOAK_MANIFEST_PATH:-/home/saurabh/...NSE_CM_EQUITY (1024).csv}`; fallback unchanged for the dev workflow |
| `ManifestLoadTest.java` | both manifest tests resolve via `INGESTION_TEST_MANIFEST_PATH` / `INGESTION_TEST_MANIFEST_1024_PATH` with the dev path as fallback; the full-manifest test now has the same existence guard as the 1024 test |
| `tests/test_audit_high_batch2.py` | the three offline guards |
