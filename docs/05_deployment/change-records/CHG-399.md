## Notes

- **FAIL is a result, not an abort:** the evidence JSON is written before the return, so a caller
  (the Monday gate, the archive runbook) can gate on the exit status without losing the record.
- **The failure signal is single-sourced:** `BUCKET_LOCK_FAILED` is used at the raise site and the
  detection site, so the two cannot drift into "prints FAILED, exits 0" again.
- **Non-fatal by design:** `NOT_SET` (no Cloudflare token) and `UNSUPPORTED` are recorded
  limitations — a host without the token must still be able to provision and record that state.
