## Notes

- **What the mutation proves:** CHG-336's defect shape (one side literal, one side
  interpolated) is exactly what the mutation re-created; the test names both maps in the
  failure, so the next person sees the divergence rather than "an assertion failed".
- **Why merge keys are safe here:** the stack already merges `*deploy_workload`/`*common_workload`
  and compose merges `*flink-common`/`*flink-common-env`; the anchor is resolved at parse time,
  so the service specs carry the same two expressions they carried as literals (verified by
  loading both decks with PyYAML).
- **Resolved values unchanged:** the replaced lines and the anchor carry the same expressions
  (`${ACCOUNT_SCOPE_ID:-prod-scope}` etc.), so a deploy that set the variables behaves
  identically; a deploy that set only one half now cannot diverge between services.
