## Notes

- **Why S1a is separate:** one commit per code region — the session module is self-contained
  and proven by its own tests before the wiring commit changes main/engine/http/client.
- **One place for ambiguity:** unknown refs and unrecognized postback event_types halt through
  the session's Send halt seam (the service binds it to the same `ServerState::safety_halt` as
  the node's `HaltNotifier`); a route postback is never dropped and never misrouted.
- **Bounded hand-off:** the node channel is the same 4096-report bound; a full/closed channel
  is treated as ambiguity (halt), never a blocking wait that would stall route bookings.
