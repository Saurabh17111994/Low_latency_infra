## Notes

- **`exitTerminalRuntime = 3` is distinct from 0/1/2** and is asserted by the Python guard so a
  future renumbering cannot silently collide with `exitFatalStart`.
- **SIGTERM handling stays faithful:** the new handler cancels on the first signal and re-raises on
  the second (via `syscall.Kill`), reproducing `signal.NotifyContext`'s documented contract — a
  stuck drain still cannot outlive a repeated SIGTERM.
- **Why the control clock split matters:** `bridge_metrics` is emitted every 10 s, inside the 15 s
  data-frame window, so before this a dead feed with a live socket looked perpetually ready.
- **The Python guard builds the bridge** (`go build`) and asserts the real process exit code in a
  subprocess; it skips when the Go toolchain is absent so a plain pytest run without Go is green.
- **Go suite scope:** the changes live in the root package and the full root-package suite is green;
  the gate additionally runs `go test -race -count=1 ./...` (root + cmd + faketool + marketdata),
  which is re-run there. (`go build ./...` alone fails on the pre-existing tagged `faketool`
  package and is not how the suite is invoked.)
