## What changed

- `run-ingestion-full.sh`: `LOG_DIR` now defaults to `<repo>/logs/ingestion` (log4j's
  `/data/ingestion/logs` does not exist on the dev host — the JSON journal was silently lost).
- Soak tools: `LOG_FILE` resolves the newest `ingestion-*.json` under
  `${SOAK_JOURNAL_DIR:-/tmp/soak-journal}` then `<repo>/logs/ingestion`; explicit paths still win.
- `POSITION_STATE_TABLE` (read by nothing) removed from `.env.example`, `docker-compose.yml`,
  `docker-stack.yml`; `INSTRUMENT_MANIFEST_VERSION` (read by code, never documented) added to
  `.env.example`.
- Live `.env` (gitignored, local): three dead EOD keys removed (`EOD_STAGING_DIR`,
  `EOD_TS_COLUMNS` — which named retired tables — `EOD_OFFLOAD_BACKEND`).
- cwd-relative evidence defaults fixed: `clean_break_drill.py`, `disaster_drills.py`,
  `stage-capture.sh` resolve under the repo root; `JobGraphDump.java` gains `JOBGRAPH_OUT_DIR`.
- `ComputeAlertLogs` now accepts `http(s)://` collector endpoints (P2-191), still rejecting
  injection-shaped values.
- `prod_vms.example.json`: personal SSH key path → `/home/<user>/…` placeholder.
- `marketdata-capture.jsonl` (capture-tool default output) untracked + ignored; local copy kept
  (the untrack landed in `2aaed4f9` due to staging order; the `.gitignore` line lands here).
- `change_control_check.py`: `change_record_id` is now a required field; the 11 legacy records
  (CHG-149…159) got their missing line.
