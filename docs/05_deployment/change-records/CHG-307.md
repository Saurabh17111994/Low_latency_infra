## What changed

The EOD controller's block-delete-unverified guard extended `table.log.ttl` with a
shadow-table rewrite (create `name__eod_ext_<date>`, copy every row via 16 threads x 500-row
upserts, count-parity, operator swap) because 0.9.1 made the option create-time only.

Fluss 1.0.0 makes `table.log.ttl` alterable **and enforced**:

| Probe | Question | Result |
|---|---|---|
| A1 (2026-09-25) | accepted + in force in ZK | GREEN |
| A2 fast (2026-09-25, 13m08s) | enforced expiry follows the ALTER, both directions | GREEN |
| A2b (2026-09-25) | enforced on existing partitions (`raw_table_1` shape) | GREEN |

`extend --apply` now runs one `Admin.alterTable(TablePath, List.of(TableChange.set("table.log.ttl",
ttl)), false)`; `performRewrite`, `COPY_THREADS`, `COPY_WRITE_BATCH`, the `__eod_ext_` shadow
naming and the copy imports are removed (~250 lines), and the old drill test is deleted.
