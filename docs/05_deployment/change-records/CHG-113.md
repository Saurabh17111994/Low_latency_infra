## Problem

`make gate` [7/13] docker build smoke and `docker compose build ddl-apply
eod-controller` failed with:

```
COPY logs/schema-compat/composite-pk-raw-client-20260815.md ... not found
```

The Dockerfile unconditionally COPY'd a **gitignored, runtime-only evidence
file** (`logs/` is ignored per R-051 — host paths, endpoints, account
identifiers). The file is absent from every clean checkout, so the image
could never build from a clean tree — a pre-existing packaging defect that
broke the gate's [8/13] image-staleness step (6 images MISSING).

## Fix

Removed the COPY line. The evidence is **optional at runtime**: the smoke
(`ddl_apply_smoke.py` `REAL_EVIDENCE` + `os.path.isfile` guard) and the
entrypoint (`ddl-apply-run.sh` env default) already fall back to a
placeholder when the file is absent — so the image needs no COPY at all.
Updated the Dockerfile comment to explain why the evidence is runtime-only.

## Impact

- `docker compose build ddl-apply eod-controller` now succeeds from a clean
  checkout (network permitting for base images).
- Runtime behavior unchanged: evidence is still picked up when mounted/present.
- COMPAT-FLUSS-005 capability evidence is still produced at runtime by the
  ddl-apply smoke; it is recorded under `logs/schema-compat/` (gitignored),
  exactly as designed.
