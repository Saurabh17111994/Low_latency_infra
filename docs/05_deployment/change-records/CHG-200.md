# CHG-200 — bench-throughput takes a free port per run; its tests skip loudly with the live stack up

- **Status:** recorded — fixed and guarded (2026-09-17)
- **Filed:** 2026-09-17
- **Source:** the `make gate` re-run after CHG-199: step [3/19] completed
  (1496 tests, 256 s) with 9 failures + 1 error, all 10 in
  `test_bench_throughput_wave33.py`.

## What happened

Two findings, one structural and one environmental:

1. The bench hardcoded broker port 8899 (8 sites in `bench-throughput.sh`,
   plus the test's FAKETOOL shims). Any stale holder — an orphaned faketool,
   a parallel run — fails every bench test with "port busy" although nothing
   is broken. Measured 2026-09-17: a stale faketool held 8899, 10 tests
   failed; port freed, 24/24 green.
2. The bench preflight refuses double-run (`pgrep -f IngestionService` →
   `preflight FAILED`). `make gate` always runs with the full stack up, and
   the ingestion process is host-PID-visible (pid 1607093 during the gate
   run), so the bench aborts and its tests fail — they can never pass
   in-gate. Standalone with the stack down they pass. The tests also leaked:
   the sandbox never stubbed the pgrep, so a live environment fails tests
   that only prove gate arithmetic.

## What changed

- `code/01_platform/04_scripts/bench-throughput.sh` —
  `BENCH_PORT="${BENCH_PORT:-8899}"` (documented next to the other
  `BENCH_*` overrides) replaces all 8 hardcoded sites (preflight, faketool
  launch, startup wait, teardown, evidence echo). Default 8899: every other
  consumer (`pipeline-lib.sh`, `run-full-suite.sh`, guards) is byte-identical
  in behavior.
- `code/01_platform/04_scripts/tests/test_bench_throughput_wave33.py` —
  (a) FAKETOOL shims bind `$W33_BROKER_PORT` (same env pattern the file
  already uses for `W33_LISTENER_PID`); the sandbox allocates a free port
  per run (`free_port`, the O2Server pattern) and exports both
  `W33_BROKER_PORT` and `BENCH_PORT`. (b) Module-level loud skip when a live
  IngestionService is detected — the bench refuses double-run by design, so
  the tests cannot pass there; `unittest.SkipTest` names the rerun condition
  (stack down). New `test_the_bench_runs_on_a_non_default_port` (healthy run
  passes with :8899 squatted) and `test_the_live_stack_probe` (probe True/False
  legs). The `:8899`-naming busy-port assertion is now port-parameterized.
- Deliberately **not** changed: the double-run refusal itself (production
  guard, must stay), and the 8899 default (other scripts depend on it).

## Known limitation

In-gate these 26 tests report SKIP, not PASS — the bench is unproven while
the stack is up. Proving it in-gate means testing against the live stack, a
larger redesign owned by a follow-up, not this fix.
