## What changed

- `RawTableColumns`: named constants for the 7 remaining raw columns —
  `VOLUME` (26, cumulative day volume), `CHANGE_FLAG` (61), `IMBALANCE_QTY`
  (66), `INDICATIVE_CLOSE_PAISE` (67), `REF_PRICE_PAISE` (68), `ATV` (70),
  `BTV` (71) — each pinned to its DDL name at class load.
- `MarketView`/`MarketSnapshot`: 7 raw getters + 7 `has*` presence getters;
  the snapshot stores a per-field seen flag, so a value the feed provided as 0
  is stored as 0 while a never-provided field stays absent (never a fabricated
  zero). Feed availability (already in the ingestion mapping): `change_flag`
  standard-token-only, `atv`/`btv` HFT-only, `imbalance`/`indicative`/`ref`
  closing-auction (CAS) only, `volume` both feeds.
- `MultiTimeframeAggregateFunction.updateMarketSnapshot`: reads the 7 columns
  when non-null, marks them seen, and counts a first sight or a change as a
  stats change — the CHG-505 market trigger and the stored state cannot
  disagree. `writeMarketSection` gained the seen-aware `setSeenLong` write.
- `CandleLiveColumns`: market section grew 44 -> 51 columns (appended after the
  two clocks, so every pre-CHG-516 index keeps its meaning); `FIELD_COUNT`
  60 -> 67, `MARKET_FIELD_COUNT` 44 -> 51.
- `StrategyHostFunction.decodeMarketSnapshot`: decodes the 7 values and their
  seen flags from the canonical row.
- `FeatureRegistry`: 10 append-only MARKET-cadence lines, ids 45..54 —
  `day_volume`, `change_flag`, `atv`, `btv`, `imbalance_qty`,
  `indicative_close_paise`, `ref_price_paise` (each gated by its own seen
  flag), `spread_paise` (ask_px_1 - bid_px_1, gate both L1 prices),
  `depth_imbalance` ((bid-ask)/(bid+ask) over the visible ladder, NaN when the
  book is empty -> skipped), `microprice_paise` (size-weighted L1, gate all
  four L1 fields). `MarketValueComputer` gained a double-valued extractor
  (the imbalance lives in [-1, 1] and must not be narrowed to a long).
- No DDL, sink, flag or operator change: the `features MAP<INT,DOUBLE>` column
  already exists.

## Why

The operator asked for the remaining per-candle numbers: the feed fields that
were present in `raw_table_1` but never reached the strategy view or storage,
plus three book metrics that were only computed on read. After this change a
reader of `candle_features` sees the raw cumulative volume, change flag, CAS
fields, ATV/BTV and the derived spread/imbalance/microprice as of each row's
close, next to the 42 values CHG-512 already stores.
