## What changed

`make drill-live`'s `-Dtest` list (Makefile) no longer begins with `EodBucketCopyIntegrationTest`; the
class was deleted with the A2 landing. The other 13 common/gateway classes and the compute list's
`B4SignalIntentE2ETest` are unchanged.

## Why it is safe

- The class file is intentionally absent: `test_eod_alter_retention.py` asserts it stays deleted, so the
  only possible fixes were removing the list entry or reintroducing a deleted test.
- `drill-live` runs with `-Dsurefire.failIfNoSpecifiedTests=false`, so the stale name was silent at
  runtime (exit 0) - the same "absence of matches read as absence" failure class this repo guards
  against; the drill-list guards are the mechanism that caught it, and they re-verified green after the
  fix.
- No live coverage is lost that still existed: the A2 landing's live verification was the ALTER probe
  (CHG-307 evidence) and its permanent guard is the Python test `test_eod_alter_retention.py` (gate
  step 3), not a Java drill.
