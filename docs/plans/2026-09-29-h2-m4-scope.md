## 4. Risks

- **Ingestion is live-shaped code** (`make test` is the area suite); S2's fatal-stop path must
  never run inline in the worker thread (self-deadlock) — the daemon-thread call is the fix, and
  the mutation "make the stop inline" must hang/fail, not flake.
- **S3/S4 cannot land before S2** (they call its handler); landing them out of order would leave
  call sites with no sink.
- **S5 touches both languages** — one commit with a Go exec-self test and a Java decision test;
  the Go exit code is asserted by subprocess, never in-process.
- **S6 fixture** must be generated from the Go carve (the reference), not hand-written; a
  divergence between the fixture and the Go carve is itself the test.
- No item needs a run >5 min; if any check grows past it, the smoke rule applies first.
