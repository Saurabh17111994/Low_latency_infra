## 2. Slices (one commit per region)

1. **S1 = H5-1** — per-rule `MapState` ledgers (`strategy-host-emitted-ids-v2/<ruleId>`); legacy
   map read-only; prune once per 16 new ids of the triggering rule (oldest detTs, null never
   evicted); no per-emission scan. Tests use real UUIDs + legacy-restore seam.
2. **S2 = H5-2** — `PER_INSTRUMENT_CAP = 20` (DEC-045 citation); the constructor rejects a
   higher rate and takes the profile explicitly; `main` passes PEAK/BASELINE without re-deriving
   the rate from it; measured wire test asserts the cap.
3. **S3 = H5-3** — per-session bounded outbox (64) + one daemon writer; `offer` drops marked on
   overflow; a 1 s watchdog evicts sessions with no progress for 5 s (socket close unblocks a
   wedged write); the shared delivery pool is deleted.

  empty); a binary rollback loses only the post-upgrade dedup window (documented in CHG-402).

  guards, the measurement uses ≥25 % headroom over the cap.
- S3 removes the P3-030 delivery-pool invariant test; its replacement pins the new single-writer +
  bounded-outbox invariants (the pool is gone, so the old test would pin nothing).
- No DDL, no cluster, no production path — compute module + mock module tests only.
