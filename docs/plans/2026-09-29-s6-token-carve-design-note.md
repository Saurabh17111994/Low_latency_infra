## 1. Verified defect (current tree)

`IngestionService.handleBridgeEvent` compares the bridge's **per-slot**
`assigned_token_set_hash` against Java's **full-set** digest:

- Field: `IngestionService.java:194` (`assignedTokenSetHash`), built at `:335-337` over ALL
  instruments via `SafetyHaltWriter.computeAssignedTokenHash(List<Long>)` (`:250-269`).
- Comparison block: comment `:1613-1633`, then
  - `:1635` `manifestFingerprint` vs the full-set digest — **correct** (P6-486: Go's
    `manifest_fingerprint` IS `tokenSetHash(allTokens)`); keep as is, metric
    `FINGERPRINT_MISMATCH`;
  - `:1641` `assignedTokenSetHash` vs the full-set digest — **the defect**: Go sets
    `SetSlotTokenHash(s.SlotID, tokenSetHash(s.Tokens))` (`go-bridge/main.go:192`), i.e. the hash
    of that slot's slice only. Any plan with more than one non-empty slot raises
    `TOKEN_HASH_MISMATCH` on every ack.

Reference carve/hash (Go):

- `subscription_plan.go:12` `MaxHFTTokensPerConnection = 1024`.
- `BuildSubscriptionPlan` (`:29-95`): copy → sort ascending → reject duplicates/non-positive →
  slice `connectionLimit` per slot, slot ids `hft-{i}`, **break when tokens run out** (no empty
  slots are emitted).
- `tokenSetHash` (`:114-127`): SHA-256 over sorted tokens, each as 8 big-endian bytes, lowercase
  hex — byte-identical to Java's `computeAssignedTokenHash`. Callers `main.go:192,194`. Existing
  Go pin test `subscription_plan_test.go:231-238`.

## 2. Design

### Go (`subscription_plan.go`)
Rename `tokenSetHash` → exported **`TokenSetHash`** (update `main.go:192,194` and
`subscription_plan_test.go:231-238`). One implementation, now callable by the fixture generator
and the Go fixture test.

### Java — new `com.trading.ingestion.safety.TokenSetHash`

```java
public enum Verdict { MATCH, MISMATCH, UNKNOWN_SLOT, EMPTY_SLICE }

public static TokenSetHash carve(List<Long> tokens, int slotCount, int connectionLimit);
public Verdict verdict(String slotId, String reportedHash);
public String expectedHash(String slotId);   // null for unknown/empty (test seam)
public Integer expectedSize(String slotId);  // null for unknown/empty (test seam)
```

- Mirrors the Go carve exactly (sort, slices of `connectionLimit`, ids `hft-{i}`).
- Unlike Go it creates a slot entry only for non-empty slices (`break` on `start >= size`), so:
  - unknown id (`core-0`, `hft-9` with `slotCount=3`, non-numeric) → `UNKNOWN_SLOT`;
  - `hft-N` inside `[0, slotCount)` with no slice → `EMPTY_SLICE` (layout drift: the bridge reports
    a slot the plan cannot fill);
  - hash equal → `MATCH`; different/null/empty → `MISMATCH`.
- Hash primitive delegates to `SafetyHaltWriter.computeAssignedTokenHash` (single Java-side
  implementation, the same one the full-set field already uses).

### Wiring (`IngestionService`)
- Field built in the constructor:
  `TokenSetHash.carve(instruments.stream().map(Instrument::instrumentToken).toList(), config.arrowHftConnections, config.arrowHftMaxTokensPerConnection)`.
- Replace the `:1641` comparison with the verdict switch (warn-only, event never rejected):
  - `MISMATCH` → existing metric `TOKEN_HASH_MISMATCH` (log has got/want, slot, epoch);
  - `UNKNOWN_SLOT` → new decode reason `TOKEN_HASH_UNKNOWN_SLOT`;
  - `EMPTY_SLICE` → new decode reason `TOKEN_HASH_EMPTY_SLICE`;
  - `MATCH` → silent.
- Update the `:1613-1633` comment: full set stays on `manifest_fingerprint`; per-slot is now
  like-for-like.

## 3. Tests / failing-first / mutations

- Failing-first: the pre-fix code is the full-set comparison; the moment the Java test drives a
  slot event with the correct per-slot digest, it must fail before the fix (mutation 2 below
  restores it and must turn the new test red).
- Mutations (one per region, transcripts under `logs/chg-381/`):
  1. `Verdict` always `MATCH` → MISMATCH/UNKNOWN_SLOT/EMPTY_SLICE tests red;
  2. comparison reverted to the full-set digest (pre-fix) → fixture/service per-slot test red;
  3. Go `TokenSetHash` byte order changed → Go fixture test + Python validator red (fixture
     consumer chain proves it is Go-derived).
- Service-level test still to scope at implementation time: find the existing harness that drives
  `handleControlRecord` with a `bridge_event`/`slot_state` payload (grep `TOKEN_HASH_MISMATCH` and
  `handleControlRecord` in `src/test`); if none exists, add one that feeds one slot_state event
  with (a) the correct per-slot digest → no warn/metric, (b) a wrong digest → `TOKEN_HASH_MISMATCH`.
- Region verification: `mvn -o test -pl 02_services/01_ingestion` + `go test .` in `go-bridge` +
  the new Python file; then `make test` + `make docs-audit`; CHG-381; flip H2-4 in the high plan;
  dossier `03-ingestion.md` slot-identity cross-check sentence.
