## 4. Risks / notes

- S1 changes seeded rules; the guard must not require a live broker — "live producer" means the
  metric name exists in a repo producer (Java/Go/Python source), which is checkable offline.
- C19's "provisions 47 rules" sentence is counted against `o2-provision.py` alone today; after the
  retirement the provisioned union equals that 47, so the sentence stays correct.
- S2's keys carry secrets **by reference** (`$${env.AWS_ACCESS_KEY_ID}`) exactly as compose does —
  never a literal; the stack's S3 credentials contract is unchanged.
- S4 changes a config type; every construction site (tests, bootstrap) is updated in the same
  commit, and the boot-refusal test pins the new fail-closed path.
